Regular Union Engine

Cross-Product DFA for L(M1) ∪ L(M2) using Parallel State Transitions

DFA UNION

How This Engine Works

This application computes the union of two regular languages represented by DFA M1 and DFA M2. It creates a cross-product DFA by processing the same input symbol in both DFAs simultaneously.

Cross Product Q = Q₁ × Q₂
Parallel Transition δ((q,p),a) = (δ₁(q,a), δ₂(p,a))
Union Acceptance q ∈ F₁ OR p ∈ F₂

STEP 02

Cross-Product States

The states of the new DFA are generated using Q₁ × Q₂. Each new state contains one state from M1 and one state from M2.

STEP 03

Parallel State Transitions

For every input symbol, both DFAs process the symbol simultaneously. The resulting pair becomes the next state of the union DFA.

STEP 04

Union Final States

A product state is final if the M1 state is final OR the M2 state is final.

F = {(q,p) | q ∈ F₁ OR p ∈ F₂}
